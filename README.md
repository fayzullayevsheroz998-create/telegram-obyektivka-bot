# Obyektivka Telegram Bot

## Настройка
1. Скопируйте `.env.example` в `.env`.
2. Заполните BOT_TOKEN, ADMIN_IDS, CARD_NUMBER, PRICE.
3. `py -m pip install -r requirements.txt`
4. `py bot.py`

Главное меню постоянно содержит Start, Новая объективка и Сменить язык. Кнопка возврата в меню работает на всех этапах.

Администратор: `/admin` — Start/Stop новых заказов и проверка платежей.
